## Como rodar localmente

```bash
git clone https://github.com/DaviOrtolan/daviortolan.github.io.git
cd daviortolan.github.io
```

Depois é só abrir o `index.html` no navegador, ou usar a extensão **Live Server** do VS Code para rodar com recarregamento automático.
